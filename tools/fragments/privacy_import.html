Import from a Microsoft export

Tick achievements from a copy of your own Xbox data, without any API key. The files you pick are read in this browser only — nothing is uploaded — and nothing is ticked until you review the analysis and confirm.

  1. Sign in at account.microsoft.com/privacy with the Microsoft account that owns the Xbox profile, then open the “Download your data” tab at the top of the page — or go straight there: account.microsoft.com/privacy/download-data.
  2. Open “Download your data”, then “Create new archive”, and tick the gaming / activity data types on offer. Microsoft does not publish a fixed list of checkboxes — include anything Xbox, gaming, or activity related.
  3. Wait for the archive: it can take minutes to hours. Under “Archives”, click Download when it is ready, and save the ZIP before it expires (archives are removed after a few days).
  4. Extract the ZIP, then choose its JSON files here (or the whole extracted folder). If a file is not JSON, it is skipped and reported below.
  5. Review the analysis, then Confirm to apply. Confident matches are records the file attributes to this game; possible matches are records with no game shown — they are held back unless you tick the box.

Microsoft does not document a filename or a field list for achievement records in the archive, and Xbox data may arrive through a separate Xbox export rather than the main archive. If the analysis finds no achievement records, the archive may simply not include them — the Xbox sync card above (once this game is mapped) is the alternative. In particular, an archive of app and service usage alone (a file like ProductAndServiceUsage.csv) lists play sessions, not achievements: it shows which apps were opened and when, with no achievement names, unlocks, or Gamerscore, so it cannot fill anything in.
