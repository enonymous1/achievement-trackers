Achievement Trackers

Welcome — pick a game, tick achievements as they pop, and watch your Gamerscore add up. Progress saves in your browser only; nothing is uploaded.

How this works

Each tracker is built from a game guide, but it is not a copy of one. Every card is an achievement — its name, Gamerscore and requirement — with the short route to that achievement underneath it. Achievements are grouped and ordered by how they typically unlock, so you can work through a game in order instead of hunting through a flat list.

Behind the scenes, one JSON file per game is the source of truth. A generator validates it (Gamerscore must sum to the declared total, IDs must be unique) and renders a tracker page from it. Adding a game means writing a JSON file, not hand-editing HTML — see the README in the repo.

Because every tracker shares this site, this hub can show your saved progress across games.
