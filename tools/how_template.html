How it works

What a tracker is, how your progress is kept, and how this site is built.

What a tracker is

Each tracker is built from a game guide, but it is not a copy of one. Every card is an achievement — its name, Gamerscore and requirement — with the short route to that achievement underneath it. Achievements are grouped and ordered by how they typically unlock, so you can work through a game in order instead of hunting through a flat list.

Route notes are short paraphrases, and every game page links back to its sources. The full guide text is never reproduced here.

The cards, up close

These are live copies of real cards, not pictures. Try them: click a header, tick steps, tap −/+. They are sandboxed — they save nothing, they cannot change your real progress, and reloading this page resets them.

Using a tracker

Tick an achievement by clicking its whole header — number, name and Gamerscore pill included. The header's state box fills green when it is done.

Sub-steps under some achievements are the route to that one achievement; ticking every sub-step ticks the achievement itself.

Counters track numbers (mobs defeated, emeralds, levels). Use the −/+ buttons beside the input, or type a number directly. Counters shared between achievements stay in sync, and each counter's progress bar sits right under its card header.

Missable: a red Missable pill means the achievement can be passed without popping — usually a choice or a one-time window, so do it when the card says to. Media: where a card has a screenshot or clip, it sits under the route note. Guide images carry their credit on the image itself, shown when you hover it (and in the viewer caption), and if one can't load, a placeholder explains why instead of a broken-image icon. Tapping a walkthrough shot opens its full-size version in a viewer on the same page. Some achievements carry a step-by-step guide instead: use Previous and Next to walk through its slides, on the card or inside the viewer — inside the viewer, tapping the left or right side of the image steps it too.

Finding things: search matches achievement names, missions and gear; the phase pills filter to one section; "Incomplete only" hides everything already done. The slim Gamerscore progress bar pins to the top while you scroll.

Your notes live on the cards: tap the note icon on any achievement card — or the note icon in the filter card for game-wide notes — and write in the popup. Notes save as you type, in your browser only, alongside your progress.

Where your progress lives

Progress saves in your browser only, one key per game — nothing is uploaded, and there is no account. That also means clearing site data, switching browsers, or using private mode starts fresh, so use Export progress before you do any of those things, and Import progress to bring a saved file back. Reset all clears one game's progress, steps, counters and notes.

Because every tracker shares this site, the hub can show your saved progress across games.

We tried the Microsoft export

We tried importing achievements from a Microsoft Privacy Dashboard archive (account.microsoft.com/privacy → Download your data → Create new archive), and it does not work as an achievement source — so the game pages no longer offer it. What the archive actually held was app and service usage: a file listing which apps were opened and when, plus search requests. It held no achievement names, no unlock dates, and no Gamerscore, so there was nothing to match against the cards — the import would have reported "no achievement records found" for every game.

That is a property of the archive, not a bug in the matching: usage sessions cannot tell you which achievements popped. What does work is the Xbox sync card on mapped games (your own OpenXBL key, in your browser only), or ticking cards by hand from your achievement list on xbox.com. If Microsoft ever ships achievement records in the archive, this section will say so and the import can return.

How the site is built

One JSON file per game is the source of truth. A generator validates it — Gamerscore must sum to the declared total, IDs must be unique, counters must be well-formed — and renders a tracker page from it. The generated pages are committed to the repo and deployed to GitHub Pages; there is no backend and no build step at deploy time.

Adding a game means writing a JSON file, not hand-editing HTML — see the README in the repo. Scope is stated honestly on each game page: a tracker that covers only part of a game's achievements says so.
